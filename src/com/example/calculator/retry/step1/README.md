### 문제
양의 정수 2개와 사칙연산 기호를 입력받아 계산 결과를 출력하는 계산기를 구현한다.

계산기는 한 번 실행되고 끝나는 것이 아니라, 사용자가 exit을 입력하기 전까지 반복해서 계산을 해야 한다.

---
### 문제 설명
java 기본 문법을 조합해서 하나의 프로그램 흐름을 만드는 것이 중요하다.

---

| 구분     | 사용한 문법                                       | 사용 이유                     |
| ------ | -------------------------------------------- | ------------------------- |
| 입력     | `Scanner`                                    | 사용자가 입력한 숫자와 연산자를 받기 위해   |
| 변수     | `int`, `double`, `char`, `String`, `boolean` | 입력값, 결과값, 상태값을 저장하기 위해    |
| 조건문    | `switch`, `if`                               | 연산자와 예외 상황을 판단하기 위해       |
| 반복문    | `while(true)`                                | `exit` 입력 전까지 계산을 반복하기 위해 |
| 형변환    | `(double)`                                   | 정수 나눗셈이 아닌 실수 나눗셈을 하기 위해  |
| 문자열 비교 | `equals()`                                   | `exit` 입력 여부를 확인하기 위해     |
| 흐름 제어  | `break`                                      | 반복문을 종료하기 위해              |

---
### 원리 그림
```
사용자
  ↓
Scanner
  ↓
num1, num2, operator 저장
  ↓
switch문으로 연산자 판단
  ↓
result 변수에 계산 결과 저장
  ↓
isValid로 정상 계산 여부 확인
  ↓
결과 출력
  ↓
exit 입력 여부 확인
```
---
### 실행 흐름도
```
프로그램 시작
      ↓
Scanner 생성
      ↓
while(true) 반복 시작
      ↓
첫 번째 숫자 입력
      ↓
두 번째 숫자 입력
      ↓
연산자 입력
      ↓
switch(operator)
      ↓
연산자가 +, -, *, / 중 하나인가?
 ┌───────────────┬────────────────┐
 │ 예             │ 아니오          │
 ↓               ↓
계산 수행        잘못된 연산자 메시지
 ↓               ↓
isValid = true   isValid = false
 ↓               ↓
결과 출력         결과 출력 안 함
      ↓
exit 입력 여부 확인
      ↓
exit인가?
 ┌───────────────┬────────────────┐
 │ 예             │ 아니오          │
 ↓               ↓
break            다시 while 처음으로
 ↓
Scanner 닫기
 ↓
프로그램 종료
```

### 코드 작성 전 생각하는 순서
#### 1. 무엇을 입력받아야 하는가?
계산을 하려면 숫자 2개와 연산자 1개가 필요하다.

#### 2. 입력값은 어떤 타입으로 저장할 것인가??

| 입력값      | 타입        | 이유                                |
| -------- | --------- | --------------------------------- |
| 첫 번째 숫자  | `int`     | 정수를 입력받기 위해                       |
| 두 번째 숫자  | `int`     | 정수를 입력받기 위해                       |
| 연산자      | `char`    | `+`, `-`, `*`, `/` 한 글자만 필요하기 때문에 |
| 결과       | `double`  | 나눗셈 결과가 소수점으로 나올 수 있기 때문에         |
| 종료 입력    | `String`  | `exit` 문자열을 입력받기 위해               |
| 계산 정상 여부 | `boolean` | 잘못된 입력일 때 결과 출력을 막기 위해            |

#### 3. 계산은 어떻게 구분할 것인가?
연산자 하나에 따라 계산 방식이 달라진다.
```
+ → 덧셈
- → 뺄셈
* → 곱셈
/ → 나눗셈
```
그래서 하나의 값에 따라 여러 경우를 나누는 `switch`문을 사용한다.

#### 4. 반복은 어떻게 처리할 것인가?
계산기는 한 번 계산하고 끝나면 안 된다.

사용자가 exit을 입력하기 전까지 계속 실행되어야 한다.

그래서 while(true)를 사용하고, exit이 입력되면 break로 반복문을 종료한다.

#### 5. 예외 상황은 무엇인가?
이번 단계에서 반드시 막아야 하는 상황은 두 가지이다.

| 상황                            | 처리                |
| ----------------------------- | ----------------- |
| 두 번째 숫자가 0인데 나눗셈을 시도함         | 메시지 출력 후 결과 출력 막기 |
| `+`, `-`, `*`, `/` 이외의 연산자 입력 | 메시지 출력 후 결과 출력 막기 |

---
### 핵심 원리
#### 1. switch문은 하나의 기준값을 여러 경우로 나눌 때 사용한다.
이번 코드의 기준값은 operator이다.
```
operator
├── +
├── -
├── *
└── /
```
따라서 if-else보다 `switch-case`가 더 읽기 쉽다.

---
#### 2. boolean은 상태를 표시하는 깃발이다.
isValid는 계산이 정상인지 아닌지를 표시한다.
```
true  → 출력 가능
false → 출력 금지
```
즉, 계산 결과 자체와 계산 성공 여부를 분리하기 위해 사용한다.

### 그냥
#### 1. if문으로도 구현할 수 있다.
이번 코드는 switch를 사용했지만, if-else if로도 구현할 수 있다.

다만 연산자처럼 하나의 값이 여러 경우로 나뉘는 상황에서는 `switch`가 더 깔끔하다.

#### 2. result를 바로 출력하지 않고 변수에 저장한 이유
이전에는 각 case 안에서 바로 출력할 수도 있었다.

하지만 이번 코드는 먼저 result에 저장한 뒤 마지막에 한 번만 출력한다.
```
계산
↓
result 저장
↓
결과 출력
```
이 구조는 STEP2에서 계산 결과를 반환하고 저장하는 구조로 자연스럽게 이어진다.
